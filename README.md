# 메모 (gs_note)

기기에만 저장되는 개인 메모앱입니다. 1단계는 안드로이드(갤럭시)용입니다.

## 지금 되는 것 (1단계)

- 메모 작성·편집, 자동 저장, 검색, 맨 위 고정
- 편집 기능은 꼭 필요한 것만: 글꼴, 글자 크기, 굵게, 글자색, 배경색 (실행 취소·다시 실행, 서식 지우기)
- 서재(폴더): 폴더 만들기·이름 바꾸기·삭제, 메모를 폴더로 이동
- 설정에서 **서재 끄기**: 폴더 없이 메모장만 사용 (폴더 정보는 지워지지 않음)
- **지문 잠금**: 앱을 열 때와 다시 돌아올 때 지문(또는 기기 PIN/패턴)으로 확인
- 모든 데이터는 이 기기에만, SQLCipher로 암호화해 저장. 암호화 키는 안드로이드 키스토어에 보관
- 구글 클라우드 백업·기기 이전에서도 제외 (`allowBackup=false`)
- **음성 메모**: 메모 화면의 마이크 버튼으로 녹음 (AAC 64kbps, 1분에 약 0.5MB). 화면이 꺼져도 녹음이 이어지고, 메모 안에서 바로 재생
- **받아쓰기**: 녹음을 마치면 기기 안의 음성 인식기로 글자로 바꿔 메모에 넣음. 인터넷·외부 서버를 쓰지 않음 (Android 13 이상, 한국어 인식 데이터가 없으면 처음에 자동으로 내려받음)
- 설정 → 음성 메모: 녹음 후 바로 받아쓰기 켜기/끄기, **글자만 동기화 / 음성 파일도 이 기기에 저장** (기기마다 따로 정함)

## 기기 동기화 (2단계)

설정 → **기기 동기화**

- **QR코드 한 번으로 기기 추가**: 쓰던 기기에서 "이 기기에 QR코드 띄우기", 새 기기에서 "QR코드 스캔해서 연결". 카메라가 없으면 "코드 복사 → 연결 코드 붙여넣기".
- **기기 수 제한 없음**: 어느 기기에서 추가해도 나머지 기기 모두가 새 기기를 알게 됩니다.
- **즉시 반영**: 한 기기에서 고치면 연결된 기기에 1초 안팎으로 반영됩니다. 열려 있는 메모도 바로 바뀝니다.
- **오프라인**: 인터넷 없이 그대로 쓰고, 다시 연결되면 밀린 변경을 자동으로 주고받습니다. 같은 메모를 양쪽에서 고쳤다면 나중에 고친 쪽이 남습니다.
- **서버 없음**: 기기끼리 직접(같은 Wi-Fi, 또는 Tailscale) AES-256 암호화로 주고받습니다. 어느 서버에도 메모가 저장되지 않습니다.
- **다른 네트워크(LTE, 다른 Wi-Fi)**: 각 기기에 Tailscale을 설치하고 같은 계정으로 켜 두면 자동으로 Tailscale 주소로 연결합니다. 못 찾으면 기기별로 주소를 직접 입력할 수 있습니다.
- **음성 메모 파일 옵션** (기기마다 따로): "텍스트만 받기(권장)" 또는 "음성 파일까지 받기".
- 기기 제거, 동기화 끄기, 동기화 그룹에서 나가기.

동기화는 앱이 열려 있는 동안 동작합니다. 꺼져 있던 기기는 다음에 열 때 밀린 내용을 받습니다.
